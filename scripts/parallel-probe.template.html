Parallel capability probe

Answers one question on the host you deploy to: can this page use more than one core, and how much would it buy? Everything below runs the real planet.wasm shader — no synthetic benchmark.

Throughput

Each worker renders whole 256×256 planet frames — same work, independent. This measures the parallel throughput the machine really has. Splitting one frame into bands gets close to it, minus the dispatch cost, which is why both are reported.

The sweep matters more than the peak: dispatch cost grows with the pool while the work per worker shrinks, so the best pool size is usually not hardwareConcurrency. And a lone worker can be scheduled onto an efficiency core on a big.LITTLE CPU, which is why the main thread is timed separately — if the two baselines disagree, believe the faster one.
